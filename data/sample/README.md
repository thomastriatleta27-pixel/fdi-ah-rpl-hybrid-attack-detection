# Amostras do conjunto de dados FDI-AH

Este diretório contém amostras pequenas destinadas à inspeção do formato
e à execução de testes rápidos.

- `dataset_node_sample.csv`: cinco registros de cada classe;
- `dataset_window_sample.csv`: cinco janelas de cada classe;
- `temporal_sequences_sample.npz`: uma sequência de cada classe;
- `temporal_sequences_sample.json`: descrição da amostra temporal.

As amostras não devem ser utilizadas para reproduzir as métricas da
dissertação. O conjunto completo será disponibilizado no Zenodo.
